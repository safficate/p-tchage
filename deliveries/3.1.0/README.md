# Pitchmap Pro 3.1.0

[Windows x64 VST3 indir](Pitchmap-Pro-3.1.0-Windows-x64.zip?raw=true) · [Ses karşılaştırmaları](Pitchmap-Pro-3.1.0-Audio-Comparisons.zip?raw=true) · [Tam kaynak ve bağımlılıklar](Pitchmap-Pro-3.1.0-Source.zip?raw=true)

ZIP'i açın. Microtonal Pitch Map Pro.vst3 klasörünün tamamını `C:\Program Files\Common Files\VST3\` içine kopyalayıp Sonar VST3 taramasını yenileyin. Ayrı installer gerekmez; paket dijital imzalı değildir.

Kanaldan çalın → ESITLE → hedef centleri değiştirin; canlı duyulur. Üst/alt küçük Dinle düğmeleri kaynak/hedef tonunu çalar: kısa tıklama yaklaşık 0,5 saniye, basılı tutma daha uzun. Tüm parça öğrenilince Tum parca burada ile ağır hazırlık, ardından Sonar Bounce. ZIP içindeki KULLANIM-3.1-TR.md ayrıntıları açıklar.

Native Linux 8/8 grup ve 135 yeni kontrol; son gerçek Windows DLL Wine altında 47 ses vakasını geçti. **Gerçek Sonar, native Windows ve hedef laptop henüz sınanmadı.** İnsan dinleme doğallığı garanti edilmez; bağımsız polifonik nota ayırma yoktur. AI ayrı OpenAI API anahtarı ister; servis bağlantısı anahtarsız doğrulanmadı.
