PITCHMAP PRO 3.0.1 — SYNTHETIC AUDIO EVIDENCE

36 controlled cases: 12 instrument-inspired stress models and six stable harmonic
fine-cent shifts, each at 44.1/48 kHz. Each rate ZIP contains 18 cases.
These are generated signals, not recordings of violin/ney/oud/etc. No private or
third-party performance audio is included. Generated by Tests/RegionalTests.cpp.

*-original.wav: original 3-second stereo audio.
*-corrected.wav: emitted corrected 3-second audio.
*-AB.wav: original then corrected, 6 seconds, without loudness normalization.
*-analysis.csv: original F0/confidence/onset/uncertainty, planned C(t), and reanalyzed
  output F0/confidence. MIDI pitch fields are continuous semitones; C is cents.
*-plan.json: requested/effective cents, calibration, actual centre verification,
  missing/out-of-precision flags, decisions/reasons and correction segments.

Requested fine-cent amounts are in the filenames. A known synthetic fundamental
is independently measured from exported WAV with a narrow-band spectral fit.
A one-cent synthetic gate is not a universal cent guarantee on recordings.

Attack protection deliberately leaves a short original interval, then bridges to
processed audio. Identified conflicting overlap groups are declined. The guitar
model does not prove reliable automatic note separation or complete tail detection.
Some output centres cannot be verified reliably; read the plan flags instead of
assuming every region reached its target.

No human blind listening panel or native Sonar test was run. Use these files for
comparison alongside the delivered test report; real instrument recordings and
native DAW acceptance remain necessary. Project license: AGPL-3.0-or-later.
