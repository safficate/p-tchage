# Validation report — Microtonal Pitch Map Pro 0.1.0

Updated: 2026-10-19 (UTC). This report describes the cloud build, not a native Windows or Sonar certification.

## Environment

Debian 13 Linux x64, GCC 14.2, CMake 3.31.10. JUCE 8.0.12 (`29396c22c93392d6738e021b83196283d6e4d850`), Signalsmith Stretch (`a670068d9aeb64913331d5cc29337b19a457a7df`), Signalsmith Linear (`146b26f91b48835d665fa0498d64d9617818d27a`). Graphic checks use Xvfb with actual JUCE components.

## Completed DSP measurements

Synthetic 2-second sine tests at both sample rates passed centre detection, +/-20 cent correction, 0/50/100% quantize, shared groups, octave-specific and independent note settings, vibrato preservation, equal/anti-phase stereo, WAV round-trip and model/settings state checks. A calibration pass was added after tests exposed small spectral-transposition errors. Playback does not run this analysis.

Source A is +10 cents above 440 Hz; target is -20 cents. Expected output centres: +10, -5, -20 cents for strengths 0, 50, 100%.

| Rate | 0% measured | 50% measured | 100% measured | +20-cent target from 440 Hz |
| --- | ---: | ---: | ---: | ---: |
| 44.1 kHz | +10.05 c | -5.17 c | -19.77 c | +19.87 c |
| 48 kHz | +10.03 c | -5.44 c | -20.11 c | +19.82 c |

Measurements are short-window YIN estimates on these synthetic signals. They do not establish universal sub-cent accuracy, natural timbre on every instrument, or target laptop performance. The zero-strength PCM test is bit-exact. Example WAV files are generated by the actual render engine.

Initial tests found a stereo startup discrepancy for identical channels. Mono-equivalent stereo is now processed once and its original channel gain/polarity is reconstructed. General stereo remains processed as a linked multi-channel spectral signal.

## Windows x64 build and validation

The Microsoft SDK network requirement was resolved during continuation. Actual Windows PE32+ x86-64 VST3 and Standalone binaries were built using Clang 19.1.7 with the MSVC ABI, MSVC CRT 14.44 and Windows SDK 10.0.26100. The CRT is linked statically. Imported DLLs are Windows system libraries; no separate Visual C++ redistributable is required by this build.

The Windows executables were run under **Wine 10 on Linux**, not on a native Windows/Sonar machine. The Windows DSP test executable completed 64 assertions at 44.1/48 kHz with exit code 0. A separate Windows executable loaded the actual PE VST3 DLL, enumerated its effect/controller classes, instantiated the component and verified stereo input/output buses; it returned 0. Windows exit codes were captured inside the Windows command interpreter, because the outer compatibility runner does not reliably propagate them.

A native AMD64 NSIS 3.11 installer was compiled without warnings. Silent installation, loading the installed VST3, uninstall registration and silent removal were exercised under Wine. Installation, installed-module load and uninstallation each returned Windows exit code 0. The application and VST3 folders were confirmed removed after normal uninstallation.

The Windows integration executable passed its assertions for parameter/source/map state restoration, default pass-through, offline render, corrected callback output at both host sample rates, bypass and timeline bounds. It also constructed the real editor. Its 2,000-block callback benchmark took 11.9632 ms in the last run. **The full Windows GUI test did not complete:** software snapshot painting stalled under Wine, including a second run without the filesystem compatibility wrapper. Those runs were stopped; they are not passing test results. The native Windows editor, actual host window, audio device and Sonar remain to be tested. The Windows deliverable is a test build with this unresolved GUI validation limitation.

The spectrogram now uses a software image to avoid GPU readback for every generated pixel on Windows. This change was compiled into the delivered plugin and standalone. The GitHub Actions workflow is provided but has not been run here.

## Scope

Implemented: monophonic WAV/host capture analysis, editable note map, pitch-class/octave targets, note override strength, group strength, offline correction, centre calibration, formant compensation, vibrato/tightness/humanize/smoothing, WAV and MIDI pitch-bend export, A/B/bypass/wet/dry, and source/map/parameter state.

Not implemented: polyphonic separation, ONNX model integration, a shared multi-stem editor, ARA, separately selectable transient protection, detailed vibrato/glide classification, and arbitrary Scala scale sizes. File length is limited to 120 seconds. These limitations are documented rather than exposed as nonfunctional controls.
