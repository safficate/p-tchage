# Licensing audit for possible commercial distribution

The project is currently AGPL-3.0-or-later. Selling copies is compatible with AGPL, but a closed-source distribution is not obtained merely by removing source ZIP links. Review the complete distribution obligations with counsel before changing the commercial model; this document records source licenses, not legal advice.
