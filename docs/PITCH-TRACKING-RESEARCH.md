# Pitch tracking: evidence, candidates and first selection

Librosa explicitly separates pYIN candidate probabilities from Viterbi voicing/sequence decoding and notes differences between the original paper and reference software. Our implementation is not named pYIN: it does not implement its threshold prior or HMM.

## Implemented staged evidence

The offline analyzer uses a 4096 window at 512-sample hops and selectively checks 8192 samples for bass, every fourth frame and discontinuities. Short 1024-sample RMS changes estimate attack evidence. Cross-resolution distance is reported as agreement/uncertainty; it is not treated as independent statistical proof. Candidate suboctaves require actual odd-harmonic support. A changing dominant partial alone does not justify relabeling a pure tone. Local robust trends identify stable anchors; uncertainty and confidence can veto processing.

Limitations: a missing fundamental with only even partials is indistinguishable from a genuine octave-up note without context. Two close players can remain coherent, whereas unrelated polyphony invalidates one-centre assumptions. Very low notes require enough periods; the fixed windows cannot guarantee bass-range accuracy at every supported input sample rate. The mandatory project rates are 44.1/48 kHz. Pitch salience probes do not constitute full multiresolution spectral separation.

`RegionalTests` records voiced coverage, octave errors on weak/changing-fundamental stress models, actual render centres and processing outcomes. Only algorithms actually run have measured results; pYIN/neural runtime figures must not be invented. Extend the corpus with licensed real signals and compare multiple detectors before replacing the current backend.
