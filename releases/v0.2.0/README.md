# Microtonal Pitch Map Pro 0.2.0 — Windows x64

[Windows VST3 + kurulum ZIP indir](https://github.com/safficate/p-tchage/raw/refs/heads/delivery/windows-v0.2.0/releases/v0.2.0/Plugin-Windows-x64.zip)

[Kaynak kod + sabitlenmiş bağımlılıklar](https://github.com/safficate/p-tchage/raw/refs/heads/delivery/windows-v0.2.0/releases/v0.2.0/Source.zip)

ZIP’i tamamen çıkarıp MicrotonalPitchMapPro-Setup-x64.exe dosyasını çalıştırın. Sonar kapalıyken eski sürümü güncelleyin, ardından VST3 taramasını yenileyin.

Üst 12 tuş ayarlanabilir referans tonu; alt 12 tuş klipteki gerçek nota örnekleridir. Alttan kaynağı, üstten hedefi seçin → ESLESTIR → HEDEFE UYGULA. Cent değeri hedef notanın ince akordudur. Do→Re/Do♯ eşlemesinde yüzde gerekmez. Sidechain isteğe bağlıdır ve yalnız eklentinin bulunduğu kanalı değiştirir.

Klipleri oynatmadan almak için hostun Region FX/ARA bağlantısı gerekir; normal kanal FX yuvası tüm proje kliplerini açmaz. WAV yükleme ve gerçek zamanlı normal FX işleme de bulunur.

Paket, test raporunu, ham test kayıtlarını, gerçek callback çıkışı WAV’larını ve lisansları içerir. Windows testleri Wine altında yürütülmüştür. **Güncel Cakewalk Sonar ve HP EliteBook üzerinde test yapılmadı; uyumluluk doğrulanmış olarak sunulmuyor.** SONAR-TEST.md bilgisayarınızda yapılacak kontrolleri açıklar.
