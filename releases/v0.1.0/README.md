# Windows x64 VST3 test sürümü — 0.1.0

[Windows ZIP paketini indir](https://github.com/safficate/p-tchage/raw/refs/heads/delivery/windows-v0.1.0/releases/v0.1.0/Plugin-Windows-x64.zip)

[Offline kaynak kodunu indir](https://github.com/safficate/p-tchage/raw/refs/heads/delivery/windows-v0.1.0/releases/v0.1.0/Source.zip)

ZIP içindeki MicrotonalPitchMapPro-Setup-x64.exe dosyasını çalıştırın. Sonar kapalıyken kurun, ardından VST3 taramasını yenileyin. Paket gerçek Windows x64 VST3 bundle ve Standalone uygulama içerir. Ayrıntılar paket içindeki WINDOWS-KURULUM.txt dosyasındadır.

Bu bir test sürümüdür. Ses motoru, gerçek Windows VST3 DLL yükleme ve kurulum/kaldırma kontrolleri Wine altında geçti. Wine altında arayüz çizim testi takıldı. Yerel Windows arayüzü, Cakewalk Sonar tarama/playback/render/proje yeniden açma ve hedef laptop performansı henüz doğrulanmadı. Ayrıntılar docs/TEST-REPORT.md ve docs/SONAR-TEST.md dosyalarındadır.

Kaynaklar ve bağımlılık bildirimleri AGPL-3.0-or-later kaynak dağıtımıyla birlikte sunulur. SHA256SUMS.txt indirme bütünlüğünü kontrol etmek içindir.
